Global Warming: 146 Years of Rising Temperatures

Exploring Earth's temperature changes from 1880 to 2025

The Central Question

How has global warming changed Earth's temperature over time, and what does the data reveal about the warming trend?

This project explores NASA GISTEMP v4 global temperature anomalies relative to the 1951–1980 average.

Read the Complete Data Story

1. Annual Temperature Trend

Created using Python and Altair. The line chart reveals yearly fluctuations and a strong long-term warming trend, particularly after 1980.

View this visualization in the complete Colab notebook.

2. Warming Stripes

Created using Google Sheets. Each vertical stripe represents one year. Blue indicates cooler years relative to the NASA baseline, while red indicates warmer years.

View the original warming stripes in the complete Colab notebook.

3. Which Decades Were the Warmest?

Created using Tableau Public. The bar chart compares average temperature anomalies by decade. The 2020s are a partial decade through 2025.

Explore the Interactive Tableau Chart

Conclusion

All three visualizations tell a consistent story: Earth's average surface temperature has increased substantially since 1880. The annual trend, warming stripes, and decade comparison provide complementary perspectives on the same warming pattern.
